# Alex Domingo — Portfolio Website

A responsive, static personal project portfolio designed for GitHub Pages. Built with plain HTML, CSS, and JavaScript; no build step or runtime dependencies.

## Preview locally

Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish on GitHub Pages

1. Create a **public** repository named `arobdomingo.github.io` on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the **root** of the repository.
3. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/(root)`. Save.
4. After deployment, the website should appear at `https://arobdomingo.github.io/`.

## Professional project descriptions

The call forecasting and call reporting projects are presented without links to private employer repositories. Review all public-facing descriptions with your employer before publishing, and avoid confidential datasets, business rules, and metrics.

## Customize

- Update project text and repository URLs in `index.html`.
- Change theme variables at the top of `styles.css`.
- Add approved screenshots or case studies as the projects mature.
- Do not publish private employer source code or confidential details.

The portfolio uses external Google Fonts; system fallback fonts remain available if the fonts cannot load.


## Project filters

The Projects area has **All**, **Personal**, **Academic**, and **Professional** filters. The two professional project cards are high-level summaries only, with no source-code or demo links. Review employer confidentiality requirements before publishing.
